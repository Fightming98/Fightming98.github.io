# 个人主页

纯 HTML / CSS / JavaScript 写的个人简介网站，无框架、无构建步骤、无依赖。
推上 GitHub Pages 即可上线。

---

## 一、文件结构

```
.
├── index.html          主页（9 个板块）
├── projects.html       项目详情子页
├── css/
│   └── style.css       全部样式，按 18 个小节组织
├── js/
│   ├── blog.js         博客文章数据 ← 加文章只改这个文件
│   └── script.js       页面交互（导航 / 动画 / 滚动高亮 / 图片兜底）
├── image/              图片放这里，见 image/README.md
├── .nojekyll           告诉 GitHub Pages 不要用 Jekyll 处理，加快部署
└── .gitignore          不提交的文件
```

**为什么没有用 React / Vue / Jekyll？**
个人简介站是纯静态内容，没有登录、没有数据库、没有跨页状态。
上框架只会带来构建步骤和依赖升级的负担，换不来任何东西。
参考站 `foxpup11.github.io` 也是这么做的。

## 二、本地预览

### 方式一：直接打开（最简单）

双击 `index.html`。

这个站没有任何网络请求（博客数据写死在 `js/blog.js` 里，不是 fetch 来的），
所以用 `file://` 协议打开和线上效果完全一致。

### 方式二：起一个本地服务器（更接近线上环境）

```bash
npx --yes serve -l 8080 .
```

然后访问 http://localhost:8080

> 什么时候必须用方式二？当你以后想加 `fetch()` 加载数据、
> 或者用 ES Module（`<script type="module">`）的时候——
> 这两种在 `file://` 下会被浏览器的跨域策略拦住。

### 改内容时的注意事项

1. **名字出现在 4 个地方**：两个文件的导航栏 + 两个文件的页脚 + 各自的 `<title>`。
2. **联系方式的 `href` 和显示文字要同步改**。
   比如改了邮箱文字但没改 `href="mailto:..."`，点了就没反应。
3. **电话号码目前是公开的**。如果不想被推销电话骚扰，
   把 `#contact` 里整个电话卡片删掉即可——留邮箱就够了。

### 增删板块

- **加一张卡片**：复制整个 `<div class="skill-card">...</div>`（或对应卡片），
  粘贴到同级位置。大部分网格是 `auto-fit` 的，会自动重排，不用改 CSS。
  **例外是证书墙**（`.cert-grid`）：它的列数是写死的
  （荣誉 5 列、软著 6 列），为的是每行都排满、不留孤零零的末行。
  增减证书之后要顺手改一下列数，否则末行会空出格子。
  具体规则见 `image/README.md` 的「证书图是怎么排的」。
- **技能卡的结构**是「图标 → 标题 → 一句话介绍 → 关键字标签」四层，
  顺序别调换，CSS 是靠这个顺序排版的。想换图标就替换那个 `<svg>` 里的
  `<path>`／`<circle>` 等图形；图标颜色由 `.skill-icon` 的 `color` 决定，
  想改成深色就把它改成 `color: var(--c-text)`。
  找图标可以去 https://lucide.dev （开源，复制 SVG 代码即可，风格和现在这套一致）。
- **删一个板块**：把整个 `<section id="xxx">...</section>` 删掉，
  记得同时把导航栏里对应的 `<li>` 删掉，否则点了会跳到页面顶部。

### 加博客文章

编辑 `js/blog.js` 里的 `POSTS` 数组：

```js
const POSTS = [
  {
    date:  '2026.08.15',
    title: '文章标题',
    desc:  '一句话摘要。',

```

主页的博客板块会自动渲染出卡片；数组为空时显示提示文字。
不想在主页列文章也行——板块里已经有一个「前往 CSDN 博客」的按钮。

## 四、改配色和字体

全站的视觉都由 `css/style.css` 开头 `:root` 里的变量控制，**改一处全站生效**。

### 换主题色

```css
--c-accent:        #1a73e8;   /* 主色，现在是 Google 蓝 */
--c-accent-hover:  #1557b0;   /* 悬停时的深色 */
--c-accent-light:  #e8f0fe;   /* 浅色底（标签背景、导航高亮） */
```

改这三个值时，`--c-accent-light` 要选主色的**很浅的版本**，
`--c-accent-hover` 选**更深的版本**。可以用 https://oklch.com 帮忙调。

几个现成的搭配：

| 风格 | accent | hover | light |
|---|---|---|---|
| 靛蓝 | `#4f46e5` | `#4338ca` | `#eef2ff` |
| 墨绿 | `#0d9488` | `#0f766e` | `#ccfbf1` |
| 酒红 | `#be123c` | `#9f1239` | `#ffe4e6` |
| 纯黑（极简） | `#111827` | `#000000` | `#f3f4f6` |

### 换字体

字体在 `index.html` 和 `projects.html` 的 `<head>` 里通过 Google Fonts 加载。
改 `--font` 变量即可：

```css
--font: 'Inter', -apple-system, 'Noto Sans SC', sans-serif;
```

> **国内访问提示**：Google Fonts 在中国大陆访问不稳定，
> 可能导致页面首屏字体闪烁或加载慢。如果主要给国内的人看，
> 建议把这两行 `<link>` 删掉——CSS 里已经写好了系统字体兜底
> （`PingFang SC`、`Microsoft YaHei`），删掉后依然正常显示，只是少了 Inter 的英文观感。

### 换内容宽度

```css
--max-w: 1200px;   /* 觉得太宽就改小，比如 1000px */
```

## 五、部署到 GitHub Pages

### 第 1 步：在 GitHub 上建仓库

登录 GitHub → 右上角 `+` → `New repository`。

**仓库名很关键，决定了你的网址：**

| 仓库名 | 网址 |
|---|---|
| `你的用户名.github.io` | `https://你的用户名.github.io/` ← 推荐，最干净 |
| `personal-website`（任意名字） | `https://你的用户名.github.io/personal-website/` |

想要 `foxpup11.github.io` 那种干净网址，**仓库名必须正好是 `<用户名>.github.io`**。

可见性选 **Public**（Private 仓库的 Pages 功能需要付费账号）。

> 本项目所有路径都写成相对路径（`css/style.css` 而不是 `/css/style.css`），
> 所以两种仓库名都能正常工作，不会出现样式丢失。

### 第 2 步：推代码上去

在本文件夹里打开终端：

```bash
git add .
git commit -m "初始化个人主页"
git branch -M main
git remote add origin https://github.com/你的用户名/仓库名.git
git push -u origin main
```

首次推送会弹出 GitHub 登录窗口，按提示授权即可。

> 如果这一步报错 `remote origin already exists`，
> 说明已经配过远程地址了，用这条覆盖：
> `git remote set-url origin https://github.com/你的用户名/仓库名.git`

### 第 3 步：打开 Pages

仓库页面 → `Settings` → 左侧 `Pages`：

- **Source** 选 `Deploy from a branch`
- **Branch** 选 `main`，目录选 `/ (root)`
- 点 `Save`

### 第 4 步：等一分钟

回到 `Actions` 标签页，能看到一个部署任务在跑。变成绿色对勾后就上线了。

访问 `https://你的用户名.github.io/`（或带仓库名的那个网址）。

> 第一次部署有时要等 2~3 分钟，页面 404 是正常的，刷新几次。
> 如果 5 分钟后还是 404，检查仓库名拼写和 Pages 设置里的分支是否选了 `main`。

### 第 5 步：以后怎么更新

改完文件后：

```bash
git add .
git commit -m "更新项目经历"
git push
```

推上去后 GitHub 会自动重新部署，一分钟左右生效。
**浏览器有缓存，看不到变化时按 `Ctrl + F5` 强制刷新。**

## 六、可选：绑定自己的域名

1. 在域名服务商（阿里云 / 腾讯云 / NameShelf 等）买一个域名
2. 在仓库 `Settings → Pages → Custom domain` 填入域名，保存
   （这会在仓库根目录自动生成一个 `CNAME` 文件）
3. 去域名服务商那里加 DNS 记录：

   | 类型 | 主机记录 | 记录值 |
   |---|---|---|
   | CNAME | `www` | `你的用户名.github.io` |
   | A | `@` | `185.199.108.153` |
   | A | `@` | `185.199.109.153` |
   | A | `@` | `185.199.110.153` |
   | A | `@` | `185.199.111.153` |

4. 等 DNS 生效（几分钟到几小时），回到 Pages 页面勾选 `Enforce HTTPS`

## 七、常见问题

**改完没变化？**
浏览器缓存。按 `Ctrl + F5` 强制刷新。线上还要多等一分钟让 GitHub 部署完成。

**样式全丢了？**
多半是文件路径问题。检查 `css/style.css` 和 `js/script.js` 是否跟着一起推上去了，
以及文件名大小写是否一致（GitHub Pages 区分大小写，Windows 不区分，
所以本地正常、线上 404 的情况八成是大小写错了）。

**图片不显示？**
显示灰色占位块说明图片没找到。检查 `image/` 里的文件名和 HTML 里写的是否完全一致。
`image/README.md` 里有完整的文件名对照表。

**导航点击没反应？**
锚点的 `href="#xxx"` 必须有对应 `<section id="xxx">`，拼写要一致。

**手机上排版乱？**
断点在 `css/style.css` 第 18 节：1024px / 768px / 480px。
用浏览器 F12 的设备模拟器可以调试。

## 八、这个站的隐私提醒

仓库是公开的，**所有内容任何人可见、可下载，且会被搜索引擎收录**。

建议不要在网站上放：

- 身份证号、学号、家庭住址
- 未打码的证书原件（获奖证书截图记得遮掉个人信息）
- 手机号（如果不想被推销电话骚扰的话——放邮箱就够了）

**`image/` 只放页面真正引用的图。** 它不是一个资料备份文件夹——
没有被 `index.html` / `projects.html` 引用的文件不会显示在页面上，
但会被完整公开，纯属白白暴露。

具体到几类材料：

| 材料 | 能不能放 |
|---|---|
| 软件著作权登记证书 | 相对安全（著作权人通常写学校），但要先确认图上无身份证号 |
| 荣誉证书 | 一般在学校的公众号上就公开过，相对安全；同上，先确认无身份证号 |
| 知识产权申请登记表、专利请求书 | **绝对不能**，上面必有第一发明人身份证号 |
| 审稿中的论文截图、投稿系统截图 | **默认不要放**，审稿期一般有保密要求——但本仓库目前有一处例外，见下 |
| 活动照片 | 有别人的正脸就先问一下对方 |
