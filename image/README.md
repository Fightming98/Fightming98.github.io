# 图片文件夹

把你自己的图片按下面的文件名放进这个文件夹，网站就会自动显示。
**文件名必须完全一致**（大小写敏感，GitHub Pages 是区分大小写的）。

## 命名约定

文件名一律用**英文小写 + 连字符**，不用中文也不用空格。

> 为什么不用中文名？中文文件名在 URL 里会被浏览器转义成一长串 `%E8%AE%BA...`，
> 分享链接、看日志、在服务器上核对文件时都很难认。英文名还有一个好处：
> 本地 Windows 不区分大小写，但 **GitHub Pages 区分**——
> 中文名出问题时排查起来更绕。

三类文件各有前缀：

| 前缀 | 用途 | 例子 |
|---|---|---|
| `activity-N` | 活动照片，按页面顺序编号 | `activity-1.jpg` |
| `copyright-<系统简称>` | 软著证书，名字即系统名 | `copyright-sst.jpg` |
| 其余按内容起名 | 荣誉证书、凭证、校徽等 | `ocean-award-2025.jpg` |

荣誉证书的命名规则是 `<荣誉简称>-<年份>.jpg`，没有年份的（如技能认证）
直接用内容命名。**改文件名之后，记得同步改 `index.html` 里的 `src`。**

## 证书图是怎么排的

荣誉和软著用的是同一套 `.cert-grid` / `.cert-card`，区别只在长宽比和列数：

| 板块 | 类名 | 证书框比例 | 列数 | 说明 |
|---|---|---|---|---|
| 个人荣誉 | `.cert-grid` | 4:3 横版 | 5 列 × 3 行 | 15 项正好排满，**点开看大图** |
| 软件著作权 | `.cert-grid.cert-grid--copyright` | 3:4 竖版 | 6 列 × 1 行 | 6 项正好排满 |
| 获奖作品 | `.work-grid` | 4:3 横版 | 2 列 × 1 行 | 各占半屏，**点开看大图** |
| 论文 / 专利 | `.paper-card--media` | 按图片原始比例 | 卡片左侧 120px | 见下 |

> **「点开看大图」是怎么实现的**：图片本身不绑点击，外面套一层
> `<button class="cert-shot" data-zoom="图片地址">`。放大的功能写在
> `js/script.js` 第 6 节，它去找页面上**所有** `[data-zoom]`，
> 所以想给别的图也加上，照抄一层按钮即可，不用改 JS。
> 按钮壳的样式（去掉默认外观、`zoom-in` 光标、悬停压暗、键盘焦点框）
> 在 `css/style.css` 里由 `.cert-shot` / `.work-shot` 共用一组规则。

比例靠 CSS 变量 `--cert-ratio` 控制，改一个数字整个板块生效。

**为什么用 `object-fit: contain` 而不是 `cover`**：证书四边都有落款、编号和
花纹，裁掉一点就可能把内容切掉。15 张荣誉证书里有 3 张是竖版，放进 4:3 的
框里会在左右留白——宁可留白，不裁内容。

**论文 / 专利那两张为什么不用固定比例**：投稿截图是横版（1065×953），
受理通知书是竖版（596×836），方向差得远，硬塞进同一个框两边都会留大白边。
这两张是单张展示、不需要和邻居对齐，所以直接按图片自己的比例排。

> **一个踩过的坑**：`<img>` 标签上的 `width` / `height` 属性会变成一条
> `height: 410px` 这样的样式提示。CSS 里只写 `aspect-ratio` 而不写
> `height: auto` 的话，覆盖不掉这个提示，图片就按原始像素高度排——
> 竖版的 2023五好学生 会撑到 856px 高，整行卡片跟着被顶高。`.cert-img`
> 里的 `height: auto` 就是干这个的，别删。

校徽用 `object-fit: contain` 显示，所以**图片本身留白多少会影响视觉大小**。
两张校徽现在都是**内容满幅**（圆环几乎顶到图片边缘），摆在一起才一样大。
换校徽时注意保持这个一致性——如果新图四周留白很多，圆标会显得小一圈。

## 换图要注意

- **保持文件名不变**。比如想换第 3 张活动照片，就用新图覆盖 `activity-3.jpg`，
  不用改 `index.html`。
- **想增删活动**：`index.html` 的 `#organization` 板块里，
  一个 `<article class="org-card">` 就是一张卡片。
  复制整块能加一项，删掉整块能减一项。网格会自动重排，不用改 CSS。
- **想加第 10 张活动图**：命名成 `activity-10.jpg`，
  在 `#organization` 里复制一张卡片，把 `src` 改成 `image/activity-10.jpg`。
- **想增删荣誉证书**：复制一整块 `<article class="cert-card">`，**连里面那层
  `<button class="cert-shot" data-zoom="...">` 一起复制**——链接和图都在按钮上，
  漏掉按钮图就点不开了。三个地方要同步改：`data-zoom`、`<img>` 的 `src`、
  `<img>` 的 `alt`（放大层大图的说明文字就是从 `alt` 取的，别留空）。
  另外 `width` / `height` 要填新图的**真实像素**，浏览器才能提前把位置留出来。
  15 项是 5 列 × 3 行的整数倍，增减后如果排不满，
  末行会空出格子——这时改一下 `.cert-grid` 的列数（`repeat(N, minmax(0, 1fr))`）。
- **想再加一张获奖作品**：复制一整块 `<article class="work-card">`。
  外面的 `<button data-zoom="图片地址">` 不能省——点击放大的功能靠它触发
  （`js/script.js` 第 6 节会去找所有带 `data-zoom` 的元素）。
  大图里显示的文字直接取按钮里那张小图的 `alt`，所以 `alt` 别留空。

## 关于体积（重要）

图片是网页体积的大头。原始的活动照片每张 800KB~1MB，9 张加起来 4.2MB，
手机上加载会明显卡顿。

**这批图已经被压缩过**，现在全站 38 张合计约 2.4MB：

| 类别 | 压缩方式 | 结果 |
|---|---|---|
| 活动照片 9 张 | 宽 760px，`-q:v 4` | 约 580KB |
| 荣誉证书 15 张 | 宽 640px，`-q:v 5` | 约 740KB |
| 软著证书 6 张 | 宽 480px，`-q:v 6` | 约 460KB |
| 凭证 2 张 | 保持原图 | 约 220KB |
| 获奖作品 2 张 | 宽 1000px，`-q:v 4` | 约 350KB |

> 作品图是唯一没有压到 640px 的一批。试过 800px，**文字明显发糊**——
> 这两张是整页文字排版，跟照片不一样，分辨率一降就不可读了。
> 1000px + `-q:v 4` 是能看清正文的最小值（800px 约 117KB，1000px 约 175KB，
> 多出来的 58KB 换来正文可读，值得）。

以后自己加图，建议也先压一下：

- 在线压缩：https://squoosh.app （Google 出品，免费，能实时对比压缩前后效果）
- 或者用 ffmpeg（如果你装了）：

  ```bash
  ffmpeg -i 原图.png -vf "scale='min(760,iw)':-2" -q:v 4 输出.jpg
  ```

- 照片存 `.jpg`，截图、图标存 `.png`
- 单张控制在 100KB 以内

### 一个真实的坑：压缩已经压过的图会变大

给软著证书做压缩时踩到过：原图 129KB，重新编码后变成 **152KB**——
**变大了**。原因是原图本来就是 JPEG，再编码一次等于把已经压过的
压缩痕迹又压一遍，质量和体积双双变差。

正确的做法是从**没压过的原图**重新出一遍，并且在缩小的同时把质量
参数调低（软著那一批是 480px + `-q:v 6`，降到 78KB）。
压缩前的原图我都备份在 `_tmp/originals/`（`_tmp/` 不进 Git）。

### 一个真实的坑：小图也可能很大

做这两张校徽时踩到过：一张 200×200 的校徽 JPEG，存出来 **560KB**。
原因是图片里嵌了一个 **544KB 的 ICC 色彩配置文件**（相机、修图软件、
从某些网站下载的图都会带），ffmpeg 默认会原样复制过去。

判断方法：图片尺寸很小但文件很大，多半就是这个原因。
解决：把 ICC 段剥掉，560KB 立刻变成 15.9KB。
本文档同目录的 `_tmp/strip.js` 就是干这个的（`_tmp/` 不进 Git）：

```bash
node _tmp/strip.js 输入.jpg 输出.jpg
```

另一个坑：**别用 `convert` 命令**。Windows 系统目录里自带一个
`C:\Windows\System32\convert.exe`，那是磁盘格式转换工具，
不是 ImageMagick——直接敲 `convert` 会调用到它，然后报一堆莫名其妙的错。
用 `ffmpeg` 或者在线工具 squoosh.app 更省事。

### 裁图别靠猜

裁方形头像或校徽时，**不要靠猜偏移量**，先把内容边界量出来再裁。
做法是转成原始灰度数据，逐像素找非白区域：

```bash
# 1. 转成原始灰度（宽高按原图填）
ffmpeg -i 原图.jpg -vf format=gray -f rawvideo /tmp/raw.bin
# 2. 用 _tmp/bbox.js 算出内容范围和中心
node _tmp/bbox.js /tmp/raw.bin 240 229
# 3. 按算出的中心裁正方形，再缩到目标尺寸
ffmpeg -i 原图.jpg -vf "crop=186:186:26:22,scale=200:200:flags=lanczos" 输出.png
```

裁方形头像可以用 ffmpeg：

```bash
# 从证件照裁出顶部正方形，再缩到 200×200
ffmpeg -i image/photo.jpg -vf "crop=295:295:0:0,scale=200:200" -q:v 3 avatar.jpg
```

`crop=宽:高:横向偏移:纵向偏移`。如果人脸偏上或偏下，调最后那个纵向偏移。

> 中原工学院那张校徽第一次就是靠猜偏移量裁的，结果圆标中心没对准，
> 左侧 ZHONGYUAN 那圈英文被切掉了。改成量边界之后才对准。

- **活动照片**：如果有其他同学的正脸，最好先问一下对方是否介意公开

- **审稿中的论文**：投稿系统截图、审稿意见默认都别放（本仓库有一处例外，见上）
- **不要放**：身份证、学生证、成绩单原件、录取通知书等含敏感信息的材料
